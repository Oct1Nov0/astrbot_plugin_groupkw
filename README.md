# 多群关键词自动回复插件（groupkw）v1.6.0

一个给 QQ 群用的关键词自动回复机器人。每个群独立配置自己的关键词，群主和管理员可以自己管理本群的内容，互不干扰。支持文字回复、图片回复、等价词。

适合把同一个机器人投放到多个群，每个群的关键词和回答都不一样的场景。

---

## 一、它能做什么

群成员在群里发消息，只要消息里**包含**某个设置好的关键词，机器人就自动回复对应的内容。回复可以是文字、图片，或图文一起。

每个群的关键词库是独立的，A 群设置的词在 B 群不会生效。

---

## 二、谁能管理

- **超级管理员**：你（机器人主人），在插件配置里填的 QQ 号。可以开启/关闭任意群，也能管理任意群的关键词。
- **群主、群管理员**：自动拥有管理本群关键词的权限，不用单独配置。他们只能管自己群的内容。
- **普通群成员**：不能管理，但发消息会触发自动回复。

---

## 三、超级管理员指令（只有你能用）

这些指令在哪里发都行（指令里带了群号）。

### 开启一个群

```
/开启 群号
```

例：`/开启 1234567`

机器人会把这个群标记为启用，并在群里发一条提示"bot已唤醒，请发送菜单查看关键词吧～"。如果这个群之前一条关键词都没有，会自动写入一套默认关键词模板（菜单、肾期、交肾等占位词），团长之后自己改内容即可。

### 关闭一个群

```
/关闭 群号
```

例：`/关闭 1234567`

关闭后这个群的自动回复停止。已经设置的关键词会保留，下次再 `/开启` 就能恢复。

---

## 四、群主、管理员指令（管理本群关键词）

以下指令群主和管理员在自己群里发即可。

### 添加文字关键词

```
/添加 关键词 回复内容
```

例：`/添加 发货 每周日统一发货哦`

之后群里有人说"什么时候发货"，机器人自动回复"每周日统一发货哦"。

### 添加图片关键词

发送图片的**同时**输入指令（图片和指令在同一条消息里发出）：

```
/添加图片 关键词 文字（文字可选）
```

例一（图文一起）：在消息里附一张收款码图片，文字写 `/添加图片 肾码 这是收款码`。之后有人说"收款"，机器人先发文字"这是本店收款码"，再发那张图。

例二（只发图）：附一张图，文字只写 `/添加图片 流程图`。之后触发只发图、不发文字。

注意：图片存的是 QQ 的图片地址，时间久了可能过期。过期后触发会回复"图片已过期，请重新配置~"，重新用 `/添加图片` 配一次即可。

### 修改关键词的文字回复

```
/修改 关键词 新回复内容
```

例：`/修改 发货 每周五发货`

### 删除关键词

```
/删除 关键词
```

例：`/删除 发货`

### 删除图片关键词

```
/删除图片 关键词
```

例：`/删除图片 收款`

### 查看本群所有关键词

```
/关键词清单
```

会列出本群所有关键词，带 `[图]` 标记的是图片关键词。

---

## 五、等价词功能

关键词的衍生说法就是等价词，比如“交肾”的等价词是“怎么肾”、“交钱”，遇到相同的关键词及其等价词，机器人会回复同一个答案。
改回复只要改主关键词的回复，所有等价词的回答跟着变。

### 添加等价词

```
/加等价词 主词 等价词
```

例：主关键词"交肾"已经配好回复后，给它加等价词：

```
/加等价词 交肾 怎么肾
```
```
/加等价词 交肾 交钱
```

之后群里说"交肾"、"怎么肾"、"交钱"，机器人都回复"交肾"对应的回答。

注意：

- 主关键词必须先存在。
- 等价词不能本身已经是另一个关键词。如果冲突，机器人会提示"该词已是其他关键词，不能设为等价词，请删除或修改关键词"。

### 删除等价词

```
/删等价词 主词 等价词
```

例：`/删等价词 交肾 交钱`

### 查看本群所有等价词

```
/等价词清单
```

按主词分组列出，例如：`交肾 ＝ 怎么肾、交钱`

---

## 六、匹配规则说明

- **包含匹配**：消息里只要包含关键词或等价词就触发，不需要完全相同。比如关键词是"发货"，有人说"啥时候发货呀"也会触发。
- **关键词优先**：先匹配关键词本身，没匹配上再看等价词。
- **匹配到第一个就回**：一条消息如果同时包含多个关键词，回复先匹配到的那一个。
- **指令不触发回复**：以 `/添加`、`/删除` 等指令开头的消息，不会被当成关键词触发回复。

---

## 七、完整使用示例

假设你（超级管理员）要给一个新群配置：

1. 你发 `/开启 1234567`，机器人在群里发唤醒提示，并自动写入默认模板。
2. 群主把模板里的占位回答改成真实内容，比如 `/修改 交肾 扫群相册肾码，备注cn加谷名`。
3. 群主加个图片关键词：附一张收款码图，文字写 `/添加图片 收款码 收款码如下`。
4. 群主给"交肾"加等价词：`/加等价词 交肾 怎么肾`、`/加等价词 交肾 交钱`。
5. 之后群成员问"怎么交钱"，机器人自动回复交肾的说明；问"收款"，机器人发收款码图。

---

## 八、安装与配置

在 AstrBot WebUI 的插件管理页面，通过 GitHub 地址安装：

```
https://github.com/Oct1Nov0/astrbot_plugin_groupkw
```

安装后在插件配置页面填入"超级管理员QQ号"（多个用英文逗号隔开）。各群群主、管理员默认可管理本群，不用在这里填。

关键词数据存放在插件目录下的 `data/groupkw.db`（SQLite），按群号隔离。
