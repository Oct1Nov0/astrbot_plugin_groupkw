# 多群关键词自动回复插件

基于 AstrBot 的关键词自动回复插件，支持每个群独立配置关键词，群主和管理员可以自助管理本群的关键词，互不干扰。适合把同一个机器人投放到多个群、每个群需要不同关键词和回答的场景。

## 功能特点

- 每个群独立的关键词库，互不影响
- 群主、管理员自动拥有本群关键词管理权限，无需单独配置
- 消息中包含关键词即触发自动回复

## 指令（群主 / 管理员可用）

- `/加词 关键词 回复内容` 添加本群关键词
- `/删词 关键词` 删除本群关键词
- `/修改 关键词 新回复内容` 修改本群关键词的回复
- `/关键词清单` 查看本群所有关键词

普通成员在群里发的消息，只要包含已设置的关键词，机器人就会自动回复对应内容。

## 安装

在 AstrBot WebUI 的插件管理页面，通过 GitHub 地址安装：

```
https://github.com/Oct1Nov0/astrbot_plugin_groupkw
```

## 配置

安装后在 AstrBot WebUI 的插件配置页面，可选填超级管理员QQ号（多个用英文逗号隔开）。超级管理员可管理任意群的关键词。各群群主、管理员默认可管理本群，无需填写。

## 示例

群主在自己群里发：

```
/加词 发货 本店每周三统一发货
/加词 怎么拍 拍下后备注谷名即可
/关键词清单
```

之后群里有人说"什么时候发货"，机器人会自动回复"本店每周三统一发货"。

## 数据存储

关键词存放在插件目录下的 `data/groupkw.db`（SQLite），按群号隔离。
